# tt-metal 0.68.0 -> 0.78.0: the change surface, partitioned

**Target: `ttnn==0.78.0`** (`23b8a7a2e7a`, 2026-09-04), the newest stable and the one
`ttx-version-recon` got opening a p300c Blackhole chip on qb2. Baseline `v0.68.0` (`6fe495cd5c5`,
2026-03-29), the pin. **6,751 commits, 19,572 files, 2,655,962 lines changed** over ten stable
minors in 159 days, median 15 days apart.

The `v0.79.0-dev20260913` nightly adds **458 commits, 3,479 files, 372,078 lines** on top. It is
tracked in the `+nightly` column but it is **not the target**: no wheel, and the porting bill is
being paid against 0.78.0. Read a nightly-only capability as a preview, not as something we can
ship behind.

Volume is generated by `artifacts/ttx/packages.py`, which takes the range as arguments and caches a
numstat per range. `new` is files present at the target that did not exist at 0.68.0 — the sharpest
single signal for a capability that could not have been used before.

## What is deliberately not packaged

Explicitly excluded: **1,974,643 lines, 74.4 % of the diff.**

| excluded | lines | why |
|---|---|---|
| `models/` | 736,720 | upstream's model zoo; we do not import it |
| `tests/` + `tt_metal/tt-llk/tests/` | 732,741 | upstream test suite |
| `experimental/quasar/` + `tt_llk_quasar/` | 154,019 | a part we do not own |
| `.github/` | 88,705 | CI |
| `tt-train/` | 79,581 | training framework; we are inference only |
| `experimental/ccl/` + `operations/ccl/` + `tt_metal/fabric/` | 84,714 | collectives and multi-host fabric. The fold is one chip and tensor parallelism is a hard stop |
| `moreh/` | 39,301 | training ops |
| `experimental/deepseek*` + `kda/` | 46,630 | LLM-specific ops the fold never calls |
| `conv/`, `pool/`, `sliding_window/` | 12,232 | no convolutions or pooling in a fold |

A further **203,528 lines (7.7 %)** are unclaimed and were checked to be uninteresting: scaleout
cabling tooling under `tools/scaleout/`, agent-config directories inside the LLK submodule
(`.claude`, `.cursor`), and ops the fold does not call (`groupnorm`, `sort`, `paged_cache`, `topk`,
`conv3d`, `batch_norm`, `ssm`, `argmax`, `sampling`). If a package agent finds a thread leading into
this residue, say so; it is a deliberate exclusion, not an oversight.

## Running a package

Each package is a set of path prefixes in `packages_0680_0780.json`. The mirror is a bare,
object-shared clone at `.ttm.git` in this worktree, so nothing needs downloading:

```
git -C .ttm.git log   --oneline v0.68.0..v0.78.0 -- <prefixes...>
git -C .ttm.git diff  -M        v0.68.0  v0.78.0 -- <prefixes...>
git -C .ttm.git grep -n '<pattern>' v0.68.0 -- <prefix>    # the before
git -C .ttm.git grep -n '<pattern>' v0.78.0 -- <prefix>    # the after
```

`packages.py` regenerates every number here; `packages.py v0.78.0 v0.79.0-dev20260913` regenerates
the `+nightly` column.
