# tt-metal 0.68.0 -> current: the change surface, partitioned

Range `v0.68.0` (`6fe495cd5c5`, 2026-03-29) to `v0.79.0-dev20260913` (`7ec1e1234ce`, 2026-09-12).
**7,152 commits, 20,300 files, 2,902,256 lines changed.** Ten stable minor releases in 159 days,
one every 15.9 days on average. Latest stable on PyPI is `ttnn==0.78.0` (2026-09-04); the pin is
`ttnn==0.68.0`.

Volume comes from `git diff --numstat -M v0.68.0 v0.79.0-dev20260913`, cached at
`artifacts/ttx/numstat_068_079.tsv`. The package definitions and the numbers below are generated by
`artifacts/ttx/packages.py` (re-runnable) into `artifacts/ttx/packages.json`.

`new` is files present at the tip that did not exist at 0.68.0 — the sharpest single signal for a
capability that could not have been used before.

## What is deliberately not packaged

Explicitly excluded: **2,178,474 lines, 75.1 % of the diff.**

| excluded | lines | why |
|---|---|---|
| `models/` | 807,596 | upstream's model zoo; we do not import it |
| `tests/` + `tt_metal/tt-llk/tests/` | 792,762 | upstream test suite |
| `ttnn/cpp/ttnn/operations/experimental/quasar/` + `tt_llk_quasar/` | 181,757 | a part we do not own |
| `tt-train/` | 80,502 | training framework; we are inference only |
| `ttnn/.../ccl/` + `operations/ccl/` + `tt_metal/fabric/` | ~75,000 | collectives and multi-host fabric. The fold is one chip and tensor parallelism is a hard stop |
| `.github/` | 94,885 | CI |
| `experimental/deepseek*`, `kda`, `fft` | ~59,000 | LLM- and signal-specific ops the fold never calls |
| `moreh/` | ~30,000 | training ops |
| `conv/`, `pool/`, `sliding_window/` | ~8,000 | no convolutions or pooling in a fold |

A further **218,623 lines (7.5 %)** are unclaimed and were checked to be uninteresting: scaleout
cabling tooling (`tools/scaleout/*`, 28,062), agent config directories inside the LLK submodule
(`.claude`, `.cursor`, `.github`, 24,466), and ops the fold does not call (`groupnorm` 11,145,
`sort` 6,465, `paged_cache` 6,028, `topk` 5,726, `conv3d` 4,031, `batch_norm` 3,063, `ssm` 2,396,
`argmax` 2,815, `sampling` 2,061). If a package agent finds a thread leading into this residue,
say so; it is a deliberate exclusion, not an oversight.

## Running a package

Each package is a set of path prefixes in `packages.json`. The mirror is a bare, object-shared
clone at `.ttm.git` in this worktree, so nothing needs downloading:

```
git -C .ttm.git log   --oneline v0.68.0..v0.79.0-dev20260913 -- <prefixes...>
git -C .ttm.git diff  -M        v0.68.0  v0.79.0-dev20260913 -- <prefixes...>
git -C .ttm.git grep -n '<pattern>' v0.68.0 -- <prefix>      # the before
git -C .ttm.git grep -n '<pattern>' v0.79.0-dev20260913 -- <prefix>   # the after
```

`packages.py` regenerates every number in this table.
