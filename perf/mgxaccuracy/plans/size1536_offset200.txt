# opened, costing about a minute of chip time. It should have been arithmetic done before the
# launch rather than caught by the harness; this row checks its FIXTURES before spending chip
# time and did not check this one's FEASIBILITY.

# the 1536 row needs a LONGER target, which is a different fixture and outside this brief.
