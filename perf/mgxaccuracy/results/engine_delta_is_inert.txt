# The 2x2's four cells did not all run the same tree (720b43a5d, d1133c67e, 07bd40614,

# including 128 changed lines of tenstorrent.py, which every model rides. The 13.04 A target
# effect is in docs/design-throughput.md, so that had to be measured rather than argued away.
#
# The control is the SAME CROP on two trees, n=8 each, everything else identical:
#
#   512 offset 0, tree 720b43a5d   n=8   median  4.748   range 0.693-12.925
#   512 offset 0, current tree     n=8   median  4.631   range 0.823-13.493
#                                        shift   0.117 A
#
#   Mann-Whitney does NOT reject: U = 28 of 64, where 32 is no difference at all. The two
#   cells are statistically indistinguishable.
#
#   target effect, as published (cross-tree)        13.04 A
#   target effect against the new same-tree cell    13.15 A
#   engine delta is 111x smaller than the effect it could have contaminated.
#
# So the cross-tree construction of the 2x2 does not threaten the target effect. The offset-100
# re-run then landed and completed the same-tree pair:
#
#   512 offset 0 / offset 100, BOTH on the current tree   4.631 -> 16.021   gap 11.39 A
#   the same pair cross-tree                              4.748 -> 17.785   gap 13.04 A
#
# The effect reproduces. What did NOT survive is the ORDERING claim the docs carried: the size
# gap at offset 0 on the after-fix engine is 19.398 - 4.631 = 14.77 A, which EXCEEDS the target
# gap either way. The doc now says the two are the same order rather than that target beats

# A SECOND THING THIS BUYS, and it is worth more than the control. These two cells are also a
# REPEAT of one configuration: same crop, same n, same everything the row controls. So they
# measure the run-to-run reproducibility of an n=8 MEDIAN.
#
# CORRECTED 2026-09-24 03:0xZ: an earlier version of this file read 0.117 A off the offset-0
