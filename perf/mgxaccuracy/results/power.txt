read it as: the smallest n whose row clears 80 %
  1.15x median shift -> more than 64 designs per size
  1.25x median shift -> more than 64 designs per size
  1.50x median shift -> n = 32 designs per size
  2.00x median shift -> n = 24 designs per size
  2.80x median shift -> n = 12 designs per size

and the floor that more designs does not move
  2 targets at 512, medians 8.46 / 10.56 -> spread 2.10 A
  A 1536 median inside 8.46-10.56 A is not evidence of a size effect at ANY n,
  because two targets of the SAME size already differ by that much. Clearing it needs
  targets, not designs: at least three per size, paired so each target is measured at both.
