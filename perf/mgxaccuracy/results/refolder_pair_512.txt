# The refolder that produces scRMSD, device against upstream fp32, on IDENTICAL designs --
# and upstream against ITSELF, which is the control that decides what the first table means.
# perf/mgxaccuracy/ref/designfolding_only.sh --from <out> --name <n>, then scrmsd.py.
#
# design       device upstream r1 upstream r2
# bg512         0.865       1.736       0.874
# bg512_1      12.897      13.688   (running)
#
# READ THE THIRD COLUMN FIRST. Two upstream runs with the same input, same config, same
# thread count and the same checkpoint give 1.736 and 0.874 A on one 80-residue refold.
# The refolder's own run-to-run spread is 0.86 A, so the 0.87 A device-to-upstream gap in
# the first table is NOT an offset -- the device's 0.865 sits at the bottom of upstream's
# own two-draw range. Nothing about the two refolders is resolvable at this n.
#
# Consequence: the 11.04-against-10.56 reference comparison needs no refolder correction,
# and a single upstream draw carries at least this much noise, which is one more reason an
# n=1 reference is a sanity check on the level rather than a test.
