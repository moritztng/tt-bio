prediction before the first number exists. This pass had no first number: every input already
existed in a committed artifact, so there was no moment before the numbers. What follows is the
hypothesis I held after reading the four source rows and before running any arithmetic, recorded so
the result can be read against it. Where a prediction was informed by something I had already seen,
