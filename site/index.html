Why it costs less

These models want many small processors, not a few huge GPUs

Small models, many small processors

A biomolecular model is 2 to 3 GB of weights, about 1 % of a B200's memory, so one prediction leaves most of a big GPU idle. A Galaxy gives every prediction its own processor: 32 run at once.

Compute-bound, so no HBM

The pairformer does N³ work on N² data: about 676 calculations per byte at 512 residues, past the point where any GPU waits on memory. Blackhole pairs GDDR6 with large on-chip SRAM instead of HBM.

Off the HBM allocation

The memory makers report their 2026 HBM output sold out. Blackhole does not use it, so you can actually buy it.

Accuracy

The same answer as the reference

Every release checks each model against its official reference implementation, run the way people use it: with an MSA wherever the model takes one.

The bar moves, so we measure it

A single reference run is not a target. The reference itself varies between seeds, so we measure that spread and land inside it.

Checked three ways

Submodule activations by correlation, end-to-end outputs on identical noise, and published benchmarks reproduced.

Every release, every model

A release ships when every model's checks pass. Per-target results, thresholds and reproduction commands are in the repository.
